# Final Reflection

### Isumi:
The most important things I learned throughout this project were the teamwork and workflow parts of software engineering. I learned more about working as a group on software projects, how an agile workflow actually feels in practice, and why CI/CD matters so much once multiple people are changing and deploying the code. The most fun part was testing things on Swagger and seeing everything actually work together end-to-end. I also enjoyed designing the recurrence class feature using a strategy design pattern, because it felt like I was directly translating something we learned in class into actual code, in a more real-world sense. The most difficult part was when refactors got messy, because one change meant that multiple files all had to be updated and kept track of and loose ends tied(because of the design principle violations I had had previously). A skill I feel more confident in now is recognizing design patterns in code and noticing code smells or places where the design can be improved. I also feel better at using GitHub in a more real collaborative way instead of just for basic version control.
